## 이 단원에서 반복해서 쓰이는 핵심 도구 6가지

| 도구 | 내용 | 까닭 |
|---|---|---|
| ① 원주각 = 중심각의 절반 | 같은 호에 대해 (원주각) = ½ × (중심각) = ½ × (호의 크기) | 중심각을 둘로 쪼개 이등변삼각형 두 개의 외각으로 보면 증명됨 |
| ② 같은 호 → 같은 원주각 | 한 호를 바라보는 원주각은 어느 점에서 재도 모두 같다 | 모두 같은 중심각의 절반이기 때문 |
| ③ 반원의 원주각 = 90° | 지름을 바라보는 원주각은 항상 90° | 지름의 중심각이 180°이고 그 절반이 90°이기 때문 |
| ④ 접선 ⊥ 반지름 | 접점에서 접선과 반지름은 수직 | 접선의 정의(원과 한 점에서만 만남)에서 나옴 |
| ⑤ 접선과 현이 이루는 각 | (접선과 현이 이루는 각) = (그 현이 만드는 반대쪽 호의 원주각) | 접선-현 각도 결국 호의 크기의 절반이기 때문 |
| ⑥ 호의 길이 ∝ 원주각 | 호의 길이와 원주각(중심각)의 크기는 정비례 | 호의 길이 = 반지름 × 중심각(라디안)이기 때문 |

원 안/밖에서 두 직선이 만날 때:
- **원 안의 교점**: (교각) = ½ × (마주 보는 두 호의 합) — 삼각형의 외각으로 증명
- **원 밖의 교점**: (교각) = ½ × (먼 호 − 가까운 호) — 역시 삼각형의 외각으로 증명

## p.52 — 문제 217 ~ 222 (접선과 원주각 / 한 호에 대한 원주각)

### 217. 두 접선과 열호 위의 원주각

**문제**: PA, PB는 원 O의 접선, ∠APB = 44°. 점 C는 **P에 가까운 쪽 호(열호) 위**에 있다. ∠ACB는?

**핵심 개념**: 접선⊥반지름(도구 ④), 사각형 내각의 합, 원주각과 중심각(도구 ①)

**풀이**:
1. PA, PB가 접선이므로 ∠PAO = ∠PBO = 90° (접선은 접점에서 반지름과 수직).
2. 사각형 APBO의 내각의 합은 360°이므로
   **∠AOB = 360° − 90° − 90° − 44° = 136°**.
3. 여기서 함정: C가 **P쪽(열호) 위**에 있다. 그러면 ∠ACB가 바라보는 호는 C를 포함하지 않는 **반대쪽 큰 호 AB**이고, 그 호의 중심각은 360° − 136°이다.
4. 원주각은 그 호의 중심각의 절반이므로
   → **∠ACB = ½ × (360° − 136°)** 를 계산하면 끝.

*까닭 체크*: 만약 C가 P 반대쪽(우호) 위에 있었다면 ½ × 136° = 68°가 되는데, 보기(108°~112°)에 없다. 그림·보기 모두 C가 열호 위임을 말해준다.

---

### 218. 두 접선 — 옳지 않은 것 고르기

**문제**: △ABC가 원 O에 내접, PA·PB는 접선, ∠P = 48°. 옳지 **않은** 것은?
① ∠PBO = 90° ② ∠AOB = 132° ③ ∠ACB = 64° ④ ∠OAB = 24° ⑤ ∠PBA = 66°

**핵심 개념**: 접선⊥반지름, 접선의 길이(PA = PB), 이등변삼각형의 밑각, 원주각=½중심각

**풀이** (보기를 하나씩 검증):
1. ① 접선 PB ⊥ 반지름 OB이므로 ∠PBO = 90° → 참.
2. ② 사각형 APBO에서 ∠AOB = 360° − 90° − 90° − 48° = 132° → 참.
3. ③ C는 P 반대쪽 큰 호 위에 있으므로 ∠ACB = ½ × ∠AOB = **½ × 132°**. 이 값이 64°인지 직접 계산해 비교해 보자. (다르면 ③이 정답)
4. ④ △OAB는 OA = OB(반지름)인 이등변삼각형 → ∠OAB = (180° − 132°) ÷ 2 = 24° → 참.
5. ⑤ PA = PB(한 외부점에서 그은 두 접선의 길이는 같다) → △PAB 이등변 → ∠PBA = (180° − 48°) ÷ 2 = 66° → 참.

→ **½ × 132° 를 계산해서 64°와 비교**하면 옳지 않은 보기가 바로 보인다.

---

### 219. 접선과 현이 이루는 각

**문제**: PA, PB는 접선, ∠APB = 68°, ∠CAB = 72°. ∠ABC를 구하시오.

**핵심 개념**: 접선의 길이(PA=PB), **접선과 현이 이루는 각**(도구 ⑤), 삼각형 내각의 합

**풀이**:
1. PA = PB이므로 △PAB는 이등변삼각형
   → ∠PAB = ∠PBA = (180° − 68°) ÷ 2 = **56°**.
2. 접선 PA와 현 AB가 이루는 각은 반대쪽 호의 원주각과 같다(도구 ⑤)
   → **∠ACB = ∠PAB = 56°**.
   *까닭*: 접선-현 각과 원주각 둘 다 "호 AB 크기의 절반"이기 때문.
3. △ABC 내각의 합:
   → **∠ABC = 180° − 72° − 56°** 를 계산하면 끝.

---

### 220. 원 밖 교점 — 외각 정리

**문제**: 두 현 AD, BC의 연장선이 원 밖 P에서 만난다. ∠P = 26°, ∠DBC = 56°. ∠ACB는?

**핵심 개념**: 삼각형의 외각 정리, 같은 호에 대한 원주각(도구 ②)

**풀이**:
1. △PBD를 보자. ∠DBC는 꼭짓점 B에서의 **외각**이다(P, B, C가 한 직선 위).
   외각 = 이웃하지 않는 두 내각의 합이므로 ∠DBC = ∠P + ∠BDP.
2. P, A, D도 한 직선 위이므로 ∠BDP = ∠ADB. 따라서
   56° = 26° + ∠ADB → **∠ADB = 30°**.
3. ∠ADB와 ∠ACB는 **같은 호 AB에 대한 원주각**이므로
   → **∠ACB = ∠ADB**. (이 값이 답)

*검산 방법*: 호로 풀어도 된다. 호 DC = 2×56° = 112°, 원 밖 교각 공식 26° = ½(호DC − 호AB)에서 호 AB를 구해 절반을 취하면 같은 값이 나온다.

---

### 221. 원 안 교점 — ∠y − ∠x

**문제**: 두 현 AC, BD가 원 안 P에서 만난다. ∠DBC = 21°, ∠APB = 65°, ∠x = ∠DAC, ∠y = ∠ADB. ∠y − ∠x는?

**핵심 개념**: 같은 호에 대한 원주각(도구 ②), 삼각형의 외각 정리

**풀이**:
1. ∠x = ∠DAC와 ∠DBC는 **같은 호 DC**를 바라보는 원주각 → **∠x = 21°**.
2. △APD에서 ∠APB는 꼭짓점 P의 외각 → ∠APB = ∠PAD + ∠PDA, 즉
   65° = ∠x + ∠y → **∠y = 65° − 21° = 44°**.
3. → **∠y − ∠x = 44° − 21°** 를 계산하면 끝.

---

### 222. 네 호의 합 = 360°

**문제**: ∠CAD = 34°, ∠ABD = 28°, ∠BDC = 60°. ∠ACB는?

**핵심 개념**: 원주각 → 호 변환(호 = 2×원주각), 원 전체 호의 합 = 360°

**풀이** (모든 각을 호로 바꾸는 것이 핵심):
1. ∠ABD = 28° 는 호 AD의 원주각 → 호 AD = 56°.
2. ∠CAD = 34° 는 호 CD의 원주각 → 호 CD = 68°.
3. ∠BDC = 60° 는 호 BC의 원주각 → 호 BC = 120°.
4. 네 호의 합이 360°이므로 호 AB = 360° − 56° − 68° − 120° = **116°**.
5. ∠ACB는 호 AB의 원주각이므로
   → **∠ACB = ½ × 116°** 를 계산하면 끝.

## p.53 — 문제 223 ~ 228 (반원의 원주각 / 원주각과 삼각비)

### 223. 반원 + 원 밖 교점

**문제**: AB는 반원 O의 지름, P는 AC·BD의 연장선의 교점, ∠COD = 32°. ∠x(=∠P)는?

**핵심 개념**: 중심각=호, 원 밖 교각 = ½(먼 호 − 가까운 호), 또는 삼각형 내각합

**풀이 1 (외부 교각 공식)**:
1. ∠COD = 32° → 호 CD = 32°.
2. P에서 두 할선(P–C–A, P–D–B)이 자르는 두 호는 **호 AB = 180°(지름)** 와 **호 CD = 32°**.
3. → **∠x = ½ × (180° − 32°)** 를 계산하면 끝.

**풀이 2 (삼각형 내각합, 까닭 확인용)**:
호 AC + 호 DB = 180° − 32° = 148°. ∠PAB = ½(호 CD + 호 DB), ∠PBA = ½(호 AC + 호 CD)이므로
∠x = 180° − ½(64° + 148°) — 같은 값이 나온다. 공식이 왜 성립하는지 보여주는 풀이.

---

### 224. 지름 위 호 쪼개기

**문제**: AD는 원 O의 지름, ∠ADB = 33°, ∠CAD = 26°. **호 BC의 중심각**은?

**핵심 개념**: 원주각→호 변환, 반원의 호 = 180°

**풀이**:
1. ∠ADB = 33° → 호 AB = 66°.
2. ∠CAD = 26° → 호 CD = 52°.
3. B, C가 지름 AD의 같은 쪽 반원 위에 있으므로 호 AB + 호 BC + 호 CD = 180°.
4. → **호 BC = 180° − 66° − 52°** 가 곧 구하는 중심각. 계산하면 끝.

*까닭*: 호의 중심각은 호의 크기 그 자체와 같다(정의).

### 225. 반원의 원주각 90° + 피타고라스

**문제**: AB는 반원 O의 지름, P는 현 AD와 BC의 교점. AP = 14, BP = 9, DP = 3. 반지름은?

**핵심 개념**: 반원의 원주각 90°(도구 ③), 피타고라스 정리 2번

**풀이**:
1. AB가 지름이므로 **∠ADB = 90°** (D는 원 위의 점).
2. 직각삼각형 PDB에서: DB = √(BP² − DP²) = √(81 − 9) = **√72 = 6√2**.
3. A, P, D는 한 직선(현 AD) 위이므로 AD = AP + PD = 14 + 3 = **17**.
4. 직각삼각형 ADB에서: AB = √(AD² + DB²) = **√(289 + 72)**.
5. → AB를 계산한 뒤 **2로 나누면** 반지름. (289+72가 제곱수인지 확인해 보자!)

---

### 226. 지름과 삼각비

**문제**: AB는 원 O의 지름, BC = 12, BO = 10. sin A × cos A × tan A 는?

**핵심 개념**: 반원의 원주각 90°, 피타고라스, 직각삼각형의 삼각비 정의

**풀이**:
1. BO는 반지름이므로 지름 AB = 20.
2. AB가 지름 → **∠ACB = 90°**.
3. AC = √(AB² − BC²) = √(400 − 144) = **16**.
4. 각 A 기준(대변 BC, 이웃변 AC, 빗변 AB):
   sin A = 12/20 = 3/5, cos A = 16/20 = 4/5, tan A = 12/16 = 3/4.
5. → **(3/5) × (4/5) × (3/4)** 를 계산하면 끝.

*빠른 까닭*: sinA·cosA·tanA = sinA·cosA·(sinA/cosA) = **sin²A**. 즉 (3/5)²과 같아야 한다 — 검산에 쓰자.

### 227. tan A와 외접원 넓이

**문제**: 원 O에 내접하는 △ABC에서 tan A = 3√3, BC = 9√3. 원 O의 넓이는?

**핵심 개념**: 같은 호에 대한 원주각(각 A를 지름 끝으로 옮기기 = 사인법칙 2R = BC/sinA), tan→sin 변환

**풀이**:
1. tan A = 3√3 이므로 밑변 1, 높이 3√3인 직각삼각형을 상상
   → 빗변 = √(1 + 27) = √28 = 2√7 → **sin A = 3√3 / (2√7)**.
2. B를 지나는 지름 BA′를 그으면 ∠BA′C = ∠A (같은 호 BC의 원주각), ∠BCA′ = 90° (지름).
   직각삼각형 A′BC에서 sin A′ = BC/BA′ 이므로 **지름 2R = BC / sin A**.
3. 2R = 9√3 ÷ [3√3/(2√7)] = 9√3 × (2√7)/(3√3) = **6√7** → R = 3√7.
4. → 넓이 = π × R² = **π × (3√7)²** 을 계산하면 끝.

---

### 228. 수선의 발과 같은 각

**문제**: 지름 AB = 6인 반원 위의 점 C에서 AB에 내린 수선의 발이 D. BC = 2√6, ∠ACD = x. sin x × cos x 는?

**핵심 개념**: 반원의 원주각 90°, 닮음에서 나오는 **같은 각 옮기기**(∠ACD = ∠ABC), 삼각비

**풀이**:
1. AB가 지름 → ∠ACB = 90°. AC = √(36 − 24) = **√12 = 2√3**.
2. **각 옮기기(핵심!)**: △ACD에서 ∠ACD = 90° − ∠A. △ACB에서도 ∠ABC = 90° − ∠A.
   → **∠ACD = ∠ABC = x**. (작은 삼각형의 각을 큰 삼각형에서 읽을 수 있게 됨)
3. 큰 직각삼각형 ACB에서 x(=∠ABC) 기준:
   sin x = AC/AB = 2√3/6 = √3/3, cos x = BC/AB = 2√6/6 = √6/3.
4. → **(√3/3) × (√6/3)** 을 계산하고 √18 = 3√2 로 정리하면 끝.

*검산*: CD = AC·BC/AB = 2√2, AD = AC²/AB = 2로 작은 삼각형에서 직접 재도 같은 값.

## p.54 — 문제 229 ~ 234 (원주각과 삼각비 / 같은 호·평행)

### 229. sin 60°와 외접원 넓이

**문제**: 원 O에 내접하는 △ABC, ∠BAC = 60°, BC = 18. 원 O의 넓이는?

**핵심 개념**: 227과 동일 — 지름 긋기(2R = BC/sin A), 특수각 sin 60° = √3/2

**풀이**:
1. B를 지나는 지름 BA′를 그으면 ∠BA′C = 60°(같은 호 BC), ∠BCA′ = 90°(지름).
2. sin 60° = 18 / (2R) → 2R = 18 ÷ (√3/2) = 36/√3 = **12√3** → R = 6√3.
3. → 넓이 = **π × (6√3)²** 을 계산하면 끝.

---

### 230. 반지름 8cm 반원에서 수선 CD

**문제**: 지름 AB, **반지름 8cm**인 반원 위 점 C에서 AB에 내린 수선의 발이 D. ∠CAB = 60°. CD는?

**핵심 개념**: 반원의 원주각 90°, 특수각 삼각비 두 번 적용

**풀이**:
1. 반지름 8cm → **AB = 16cm**. AB가 지름 → ∠ACB = 90°.
2. 직각삼각형 ACB에서: AC = AB × cos 60° = 16 × ½ = **8cm**.
3. 직각삼각형 ACD에서(∠ADC = 90°): CD = AC × sin 60° = **8 × (√3/2)** → 계산하면 끝.

*검산*: BC = 16·sin60° = 8√3, CD = AC·BC/AB 로 재도 같은 값.

### 231. 둘레 구하기

**문제**: AB가 지름, 반지름 3cm인 원 O에 △ABC가 내접. ∠CAB = 30°. △ABC의 둘레는?

**핵심 개념**: 반원의 원주각 90°, sin 30° = ½, cos 30° = √3/2

**풀이**:
1. AB = 6cm(지름), ∠ACB = 90°.
2. BC = AB × sin 30° = 6 × ½ = **3cm**.
3. AC = AB × cos 30° = 6 × (√3/2) = **3√3 cm**.
4. → 둘레 = **6 + 3 + 3√3** (cm). 정리하면 끝.

---

### 232. 평행한 현 + 같은 호

**문제**: AD ∥ BE, 호 AB = 호 BC, ∠ADC = 56°. ∠DCE는?

**핵심 개념**: 같은 호 → 같은 원주각, **평행한 두 현 사이에 끼인 호는 같다**(엇각 이용)

**풀이**:
1. 호 AB = 호 BC 이므로 D에서 본 두 원주각이 같다: ∠ADB = ∠BDC.
   ∠ADC = 56°가 둘로 똑같이 나뉘므로 **∠ADB = 28°** (= 호 AB의 원주각).
2. **평행선 까닭**: AD ∥ BE에 가로선 BD를 그으면 엇각으로 ∠DBE = ∠ADB = 28°.
   ∠DBE는 호 DE의 원주각이므로 **호 DE = 호 AB** (같은 원주각 ↔ 같은 호).
3. ∠DCE는 호 DE에 대한 원주각 → 같은 호를 보는 ∠DBE와 같다.
   → **∠DCE = ∠DBE** = (1번에서 구한 값). 끝.

### 233. 호 3등분 + 원 밖 교점

**문제**: 호 AB = 호 BC = 호 DA, P는 AD·BC의 연장선의 교점, ∠P = 44°. ∠ADB를 구하시오.

**핵심 개념**: 호의 합 = 360°, 원 밖 교각 = ½(먼 호 − 가까운 호), 원주각 = ½호

**풀이**:
1. 호 AB = 호 BC = 호 DA = x 라 하면 호 CD = 360° − 3x.
2. P에서 가까운 호는 AB, 먼 호는 CD이므로
   44° = ½ × [(360° − 3x) − x] = 180° − 2x.
3. 풀면 2x = 136° → **x = 68°** (호 AB의 크기).
4. ∠ADB는 호 AB의 원주각이므로 → **∠ADB = ½ × 68°** 를 계산하면 끝.

*검산*: 호 CD = 360−204 = 156° > 0, (½·156) − (½·68) = 44° = ∠P ✓

### 234. 반원에서 호의 이등분

**문제**: AB는 반원 O의 지름, 호 BD = 호 CD, ∠ABC = 42°. ∠CBD는?

**핵심 개념**: 반원의 호 = 180°, 원주각→호, 같은 호의 이등분

**풀이**:
1. ∠ABC = 42° → 호 AC = 84°.
2. 나머지 호 CB = 180° − 84° = **96°**.
3. 호 CD = 호 DB 이므로 D는 호 CB의 중점 → 호 CD = 96° ÷ 2 = **48°**.
4. ∠CBD는 호 CD의 원주각 → **∠CBD = ½ × 48°** 를 계산하면 끝.

*검산*: ∠ABD = 42° + (구한 값) 이 호 AD = 84° + 48° 의 절반과 일치하는지 확인.

## p.55 — 문제 235 ~ 240 (원주각과 호의 길이 비례)

### 235. 우각(반대쪽 중심각) 240°

**문제**: 원 O에서 호 PB = ⅓ × 호 PA. 그림에서 P 반대쪽 중심각(우각) ∠AOB = 240°. ∠PBA는?

**핵심 개념**: 중심각의 합 = 360°, 호의 비 = 중심각의 비, 원주각 = ½중심각

**풀이**:
1. P를 포함하지 않는 쪽 호 AB의 중심각이 240°이므로, P를 포함하는 쪽
   호 APB의 중심각 합 = 360° − 240° = **120°**.
2. 호 PA : 호 PB = 3 : 1 이므로 120°를 3:1로 나누면
   호 PA = 120° × ¾ = **90°**, 호 PB = 30°.
3. ∠PBA는 호 PA(B를 포함하지 않는 호)의 원주각
   → **∠PBA = ½ × 90°** 를 계산하면 끝.

*검산*: ∠PAB = ½×30° = 15°, ∠APB = ½×240° = 120°, 세 각의 합 = 180° ✓

### 236. 중심에서 같은 거리의 두 현

**문제**: 외심 O에서 AB, AC에 내린 수선의 발 M, N에 대해 OM = ON. ∠ACB = 75°, 호 AB = 25π. 호 BC의 길이를 구하시오.

**핵심 개념**: **중심에서 같은 거리에 있는 두 현은 길이가 같다**, 이등변삼각형, 호의 길이 ∝ 원주각(도구 ⑥)

**풀이**:
1. OM = ON → 두 현이 중심에서 같은 거리 → **AB = AC**.
2. △ABC는 이등변 → ∠ABC = ∠ACB = 75° → ∠BAC = 180° − 150° = **30°**.
3. 호의 길이는 그 호를 바라보는 원주각에 정비례한다:
   호 AB : 호 BC = ∠ACB : ∠BAC = 75 : 30.
4. → **호 BC = 25π × (30/75)** 를 계산하면 끝.

### 237. 내접 정삼각형 + 내접 정사각형

**문제**: 원 O에 정삼각형 ABC와 정사각형 ADEF가 내접(A 공통). 호 DB = 5π. 반지름은?

**핵심 개념**: 정n각형의 이웃 꼭짓점 사이 호 = 360°/n, 호의 길이 = (중심각/360°) × 2πr

**풀이**:
1. 정사각형: 호 AD = 360° ÷ 4 = **90°**.
2. 정삼각형: 호 AB = 360° ÷ 3 = **120°**.
3. D와 B가 A로부터 같은 방향에 있으므로 호 DB = 120° − 90° = **30°**.
4. 호 DB의 길이: 5π = 2πr × (30/360) = πr/6.
5. → **r = 5π × 6 ÷ π** 를 계산하면 끝.

### 238. 호의 비 3 : 4 : 5

**문제**: 호 AB : 호 BC : 호 CA = 3 : 4 : 5. ∠BAC = a°, ∠ABC = b°, ∠BCA = c°일 때 b − a + c 는?

**핵심 개념**: 삼각형 세 내각은 세 호의 원주각 → 합이 180°이고 호의 비대로 나뉨

**풀이**:
1. 세 호의 원주각의 합 = 180° (호 전체 360°의 절반). 내각은 3:4:5로 180°를 나눈다.
2. 각은 **자기 맞은편 호**를 바라본다:
   c°(∠BCA) ← 호 AB = 180° × 3/12 = **45°**
   a°(∠BAC) ← 호 BC = 180° × 4/12 = **60°**
   b°(∠ABC) ← 호 CA = 180° × 5/12 = **75°**
3. → **b − a + c = 75 − 60 + 45** 를 계산하면 끝.

*까닭 체크*: a + b + c = 180 인지 먼저 확인하면 실수를 잡을 수 있다.

### 239. 대관람차 10칸 (⚠ 그림 주의)

**문제**: 대관람차 10개의 칸이 등간격. 그림처럼 두 현이 원 **안에서 교차**할 때 ∠x는?

**핵심 개념**: 등분 → 한 칸 사이 호 = 360° ÷ 10 = 36°, **원 안 교각 = ½(마주 보는 두 호의 합)**

**풀이** (검증 단계에서 그림을 재판독해 확정한 구성):
1. 이웃 칸 사이 호 = 36°.
2. 그림의 두 선분은 한 칸에서 나온 것이 **아니라**, 서로 다른 두 현이 원 안의 한 점에서 교차한다: 10시 칸→1시 칸 현, 11시 칸→5시 칸 현.
3. ∠x가 마주 보는 두 호: 한쪽은 칸 간격 **1개분(36°)**, 반대쪽은 칸 간격 **3개분(108°)**.
4. 원 안 교각 공식(삼각형 외각으로 증명됨):
   → **∠x = ½ × (36° + 108°)** 를 계산하면 끝.

*까닭(공식 증명)*: 교점을 P라 하고 한 현의 끝과 삼각형을 만들면, ∠x는 그 삼각형의 외각 = 두 원주각의 합 = ½(호₁) + ½(호₂).

### 240. 같은 호 2쌍 + 원 안 교점

**문제**: 호 AB = 호 BC, 호 AE = 호 ED. P = AD∩BE, Q = AC∩BE. ∠DAC = 34°. ∠APQ는?

**핵심 개념**: 원주각→호, 호의 합 = 360°, 원 안 교각 = ½(마주 보는 두 호의 합)

**풀이**:
1. ∠DAC = 34° → **호 DC = 68°**.
2. 호 AB = 호 BC = a, 호 AE = 호 ED = b 라 하면
   2a + 2b + 68° = 360° → **a + b = 146°**.
   (a, b를 따로 구할 필요가 없다는 것이 이 문제의 묘미!)
3. 현 AD와 BE의 교점 P에서:
   ∠APB = ½ × (호 AB + 호 ED) = ½ × (a + b).
4. Q는 BE 위에서 P보다 B쪽에 있으므로 반직선 PQ = 반직선 PB
   → **∠APQ = ∠APB = ½ × 146°** 를 계산하면 끝.
