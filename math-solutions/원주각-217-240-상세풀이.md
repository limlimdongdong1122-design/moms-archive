# 0부. 시작하기 전에 — 이 단원의 무기들과 "왜 그런지"

원주각 단원의 모든 문제는 아래 7가지 도구의 조합입니다.
공식만 외우면 응용문제에서 무너지므로, **각 도구가 왜 성립하는지(까닭)** 를 먼저 이해합시다.

## 도구 1. 원주각은 중심각의 절반이다

> 한 호 AB에 대하여: **(원주각 ∠APB) = ½ × (중심각 ∠AOB) = ½ × (호 AB의 크기)**

**까닭(증명 스케치)**: 원 위의 점 P에서 중심 O를 지나는 지름 PQ를 그어 보세요.
- △OPA는 OP = OA (둘 다 반지름)인 **이등변삼각형**이므로 두 밑각이 같습니다: ∠OPA = ∠OAP.
- 삼각형의 외각 정리에 의해 ∠AOQ = ∠OPA + ∠OAP = **2∠OPA**.
- 같은 방법으로 ∠BOQ = 2∠OPB.
- 두 식을 더하면(또는 빼면) ∠AOB = 2∠APB. 그래서 원주각은 항상 중심각의 절반입니다. ∎

여기서 따라 나오는 두 가지:
- **도구 2. 같은 호를 바라보는 원주각은 모두 같다.** (모두 같은 중심각의 절반이니까)
- **도구 3. 지름(반원)을 바라보는 원주각은 90°.** (지름의 중심각 = 180°, 그 절반 = 90°)

## 도구 4. 접선은 접점에서 반지름과 수직이다

**까닭**: 접선은 원과 딱 한 점에서만 만나는 직선입니다. 만약 반지름과 수직이 아니라면, 중심에서 접선까지의 최단거리(수선)가 반지름보다 짧아져서 직선이 원을 **두 점**에서 뚫고 지나가게 됩니다. 이는 접선의 정의에 모순이므로, 접선 ⊥ 반지름일 수밖에 없습니다. ∎

**함께 쓰는 성질**: 원 밖의 한 점 P에서 그은 두 접선의 길이는 같다 (PA = PB).
*까닭*: △PAO ≡ △PBO (빗변 PO 공통, OA = OB = 반지름, 직각) — RHS 합동.

## 도구 5. 접선과 현이 이루는 각 = 그 현이 만드는 반대쪽 호의 원주각

> 접선 PT와 현 AB가 접점 A에서 이루는 각 ∠TAB = 반대쪽 호에 대한 원주각 ∠ACB

**까닭(간단 증명)**: 접점 A에서 지름을 그으면, 접선⊥지름이므로 ∠TAB = 90° − (지름과 현 AB 사이 각). 그런데 반원의 원주각을 이용하면 ∠ACB도 정확히 같은 값이 됩니다. 결국 둘 다 "호 AB 크기의 절반"이라서 같습니다. ∎

## 도구 6. 호의 길이는 원주각(중심각)의 크기에 정비례한다

**까닭**: 호의 길이 = 반지름 × 중심각(라디안). 한 원에서 반지름은 고정이므로 호의 길이는 중심각에 정비례하고, 원주각은 중심각의 절반이므로 원주각에도 정비례합니다. ∎

따라서: **호의 비 = 중심각의 비 = 원주각의 비**, 그리고 **한 원에서 모든 호에 대한 원주각의 총합 = 360°의 절반 = 180°** (삼각형 내각의 합이 180°인 것과 정확히 맞물립니다!)

## 도구 7. 두 직선의 교점 위치에 따른 각 공식 (외각 정리에서 유도)

**(a) 교점이 원 안에 있을 때** — 두 현 AC, BD가 원 안의 점 P에서 교차하면:

> ∠APB = ½ × (호 AB + 호 CD)  (마주 보는 두 호의 합의 절반)

*까닭*: 보조선 AD를 그으면 ∠APB는 △APD의 꼭짓점 P에서의 **외각**입니다.
외각 = 이웃하지 않는 두 내각의 합 = ∠ADB + ∠DAC = ½호AB + ½호CD. ∎

**(b) 교점이 원 밖에 있을 때** — 두 할선이 원 밖의 점 P에서 만나면:

> ∠P = ½ × (먼 호 − 가까운 호)

*까닭*: 역시 보조선을 그으면 "먼 호의 원주각"이 삼각형의 외각이 되어,
(먼 호의 원주각) = ∠P + (가까운 호의 원주각) 이 성립하기 때문입니다. ∎

**공식을 못 외웠어도** 삼각형의 외각 정리만 기억하면 그 자리에서 유도할 수 있습니다.
실제로 아래 풀이에서는 공식과 외각 정리 두 가지 방법을 모두 보여줍니다.

## 문제 217 — 두 접선과 "열호 위의 점"

### 문제 상황
- 원 O 밖의 점 P에서 두 접선을 그어 접점이 A(위), B(아래).
- ∠APB = 44°.
- **점 C가 P에 가까운 쪽 호(작은 호, 열호) 위에 있음** ← 이 문제의 핵심 포인트!
- ∠ACB의 크기는? (보기: 108°~112°)

### 사용 도구
도구 4 (접선⊥반지름), 사각형 내각합 360°, 도구 1 (원주각 = ½중심각)

### 풀이

**1단계 — 중심각 ∠AOB 구하기.**
PA, PB가 접선이므로 ∠PAO = ∠PBO = 90° (도구 4).
사각형 APBO의 내각의 합은 360°이므로:

∠AOB = 360° − 90° − 90° − 44° = **136°**

> 💡 이 관계는 공식으로 기억해도 좋습니다: **∠P + ∠AOB = 180°** (두 직각이 있으니 나머지 두 각의 합이 180°). 접선 문제에서 매번 나옵니다.

**2단계 — C가 어느 호 위에 있는지 확인 (함정 구간!).**
원주각 ∠ACB가 바라보는 호는 "C를 **포함하지 않는** 쪽의 호 AB"입니다.
- C가 P **반대쪽**(큰 호) 위라면: ∠ACB = ½ × 136° = 68°.
- 그런데 보기가 108°~112°이므로 68°는 답일 수 없다 → 그림대로 **C는 P쪽 작은 호 위**.
- 그러면 ∠ACB가 바라보는 호는 반대쪽 **큰 호 AB**이고, 그 중심각은 360° − 136° = 224°.

**3단계 — 원주각 계산.**

**→ 계산: ∠ACB = ½ × 224°**

### 자주 하는 실수
무조건 ½ × 136° = 68°로 계산하는 것. **C의 위치**에 따라 바라보는 호가 달라집니다. "내가 구하는 원주각의 꼭짓점이 어느 호 위에 있는가?"를 항상 먼저 확인하세요.

### 검산
∠ACB(구한 값) + 68° = 180° 가 되어야 합니다. (원에 내접하는 사각형의 마주 보는 각의 합 = 180°와 같은 원리 — 두 호의 합이 360°이므로 두 원주각의 합은 180°.)

## 문제 218 — 두 접선, 보기 5개 전수 검증

### 문제 상황
- △ABC가 원 O에 내접, PA·PB는 각각 A, B에서의 접선, ∠P = 48°.
- **옳지 않은 것**은?
  ① ∠PBO = 90° ② ∠AOB = 132° ③ ∠ACB = 64° ④ ∠OAB = 24° ⑤ ∠PBA = 66°

### 사용 도구
도구 4 (접선⊥반지름), 접선의 길이(PA=PB), 이등변삼각형의 밑각, 도구 1

### 풀이 — 보기를 하나씩 판정

**① ∠PBO = 90°?**
PB는 접선, OB는 접점으로 가는 반지름 → 수직 (도구 4). **참.**

**② ∠AOB = 132°?**
사각형 APBO에서 ∠AOB = 360° − 90° − 90° − 48° = 132°. **참.**
(217에서 본 ∠P + ∠AOB = 180° 공식으로도: 180° − 48° = 132°.)

**③ ∠ACB = 64°?**
C는 P 반대쪽 큰 호 위에 있으므로 ∠ACB는 작은 호 AB(중심각 132°)를 바라보는 원주각.
∠ACB = ½ × 132°.
**→ 계산: ½ × 132° 를 구해 64°와 같은지 비교** — 다르면 ③이 "옳지 않은 것".

**④ ∠OAB = 24°?**
△OAB는 OA = OB(반지름)인 이등변삼각형. 꼭지각 ∠AOB = 132°이므로
밑각 ∠OAB = (180° − 132°) ÷ 2 = 24°. **참.**

**⑤ ∠PBA = 66°?**
PA = PB (한 점에서 그은 두 접선의 길이는 같다) → △PAB는 이등변삼각형.
∠PBA = (180° − 48°) ÷ 2 = 66°. **참.**
*교차 확인*: 접선-현 각(도구 5)으로 ∠PBA = ∠ACB 여야 하는데, ③에서 구한 값과 정말 같은지 확인해 보세요. 같아야 정상입니다!

### 정리
①②④⑤가 모두 참임을 확인했으므로, ③의 값만 직접 계산해 보면 옳지 않은 보기가 확정됩니다.

## 문제 219 — 접선과 현이 이루는 각

### 문제 상황
- PA, PB는 원 O의 접선 (접점 A, B), ∠APB = 68°.
- C는 원 위의 점, ∠CAB = 72°.
- ∠ABC를 구하시오. (주관식)

### 사용 도구
접선의 길이(PA=PB), **도구 5 (접선-현 각)**, 삼각형 내각의 합

### 풀이

**1단계 — 이등변삼각형 PAB에서 밑각 구하기.**
PA = PB이므로 △PAB는 이등변삼각형.

∠PAB = ∠PBA = (180° − 68°) ÷ 2 = **56°**

**2단계 — 접선-현 각을 원주각으로 옮기기 (핵심!).**
접선 PA와 현 AB가 이루는 각 ∠PAB는, 현 AB가 만드는 **반대쪽 호의 원주각**과 같습니다 (도구 5):

∠ACB = ∠PAB = **56°**

> 💡 까닭 다시 보기: ∠PAB도, ∠ACB도 결국 "호 AB(작은 호) 크기의 절반"이기 때문에 같습니다.

**3단계 — 삼각형 내각의 합.**
△ABC에서 세 내각의 합은 180°이므로:

**→ 계산: ∠ABC = 180° − 72° − 56°**

### 자주 하는 실수
∠CAB = 72°를 접선-현 각으로 착각하는 것. 72°는 **현 CA와 현 AB 사이의 각**(순수한 원주각 쪽 각)이고, 접선-현 각은 ∠PAB = 56° 쪽입니다. 그림에서 접선이 어느 선인지 색칠하며 구분하세요.

## 문제 220 — 원 밖 교점: 외각 정리로 푸는 법

### 문제 상황
- 두 현 AD, BC의 연장선이 원 **밖**의 점 P에서 만남 (P–A–D, P–B–C 순서로 한 직선).
- ∠P = 26°, ∠DBC = 56°.
- ∠ACB는? (보기: 27°~31°)

### 사용 도구
삼각형의 외각 정리, 도구 2 (같은 호 → 같은 원주각), (검산용) 도구 7(b)

### 풀이

**1단계 — 외각 정리 세우기.**
△PBD를 봅시다. 점 B에서 P, B, C가 한 직선 위에 있으므로 ∠DBC는 △PBD의 꼭짓점 B에서의 **외각**입니다.

외각 = 이웃하지 않는 두 내각의 합: ∠DBC = ∠P + ∠PDB
56° = 26° + ∠PDB → ∠PDB = 30°

**2단계 — ∠PDB를 원주각으로 읽기.**
P, A, D가 한 직선 위에 있으므로 ∠PDB = ∠ADB. 즉 **∠ADB = 30°**.

**3단계 — 같은 호로 옮기기.**
∠ADB와 ∠ACB는 둘 다 **호 AB**를 바라보는 원주각 (도구 2).

**→ 계산(확인): ∠ACB = ∠ADB = ?** (2단계에서 이미 나온 값 — 그대로 쓰면 됩니다)

### 다른 풀이 (호 공식, 도구 7(b))
∠DBC = 56° → 호 DC = 112°. 원 밖 교각 공식: 26° = ½(호 DC − 호 AB) = ½(112° − 호 AB).
여기서 호 AB를 구한 뒤 절반을 취하면 같은 답이 나옵니다. 두 방법이 일치하는지 꼭 비교해 보세요.

### 자주 하는 실수
"먼 호"와 "가까운 호"를 반대로 넣는 것. P에서 볼 때 A, B가 가깝고 D, C가 멀기 때문에 (먼 호 DC − 가까운 호 AB)입니다. 헷갈리면 공식 대신 외각 정리(1단계 방식)를 쓰세요 — 절대 안 헷갈립니다.

## 문제 221 — 원 안 교점: ∠y − ∠x

### 문제 상황
- 두 현 AC와 BD가 원 **안**의 점 P에서 교차.
- ∠DBC = 21°, ∠APB = 65°.
- ∠x = ∠DAC (점 A의 각), ∠y = ∠ADB (점 D의 각).
- ∠y − ∠x는? (보기: 23°~27°)

### 사용 도구
도구 2 (같은 호 → 같은 원주각), 삼각형의 외각 정리

### 풀이

**1단계 — ∠x를 아는 각으로 바꾸기.**
∠x = ∠DAC와 ∠DBC는 둘 다 **호 DC**를 바라보는 원주각입니다 (도구 2).

∠x = ∠DBC = **21°**

**2단계 — 외각 정리로 ∠y 구하기.**
△APD에서 ∠APB는 꼭짓점 P에서의 **외각** (A, P, C가 한 직선, B, P, D가 한 직선이므로).

∠APB = ∠PAD + ∠PDA → 65° = ∠x + ∠y → ∠y = 65° − 21° = **44°**

> 💡 이것이 바로 도구 7(a) "원 안 교각 = 마주 보는 두 호의 합의 절반"의 정체입니다:
> 65° = ½(호 AB + 호 DC) = ∠ADB + ∠DBC.

**3단계 — 차 구하기.**

**→ 계산: ∠y − ∠x = 44° − 21°**

### 검산 (호로 다시 풀기)
호 DC = 2 × 21° = 42°. 65° = ½(호 AB + 42°) → 호 AB = 88° → ∠ADB = 44°. 일치! ✓

## 문제 222 — 모든 각을 호로 바꿔 360° 채우기

### 문제 상황
- 원 위의 네 점 A, D, C, B. 현들이 그려져 있고:
- ∠CAD = 34°, ∠ABD = 28°, ∠BDC = 60°.
- ∠ACB는? (보기: 57°~61°)

### 사용 도구
도구 1 (호 = 2 × 원주각), 원 전체 호의 합 = 360°

### 풀이 — "각 → 호 → 각" 왕복 전략

이런 문제(여러 각이 흩어져 있는 문제)는 **모든 원주각을 호로 환산**하는 것이 정석입니다.
각은 위치에 따라 다르게 보이지만, 호는 원 위에 고정된 "공용 화폐"이기 때문입니다.

**1단계 — 주어진 세 각을 호로 환산.**
| 주어진 각 | 바라보는 호 | 호의 크기 |
|---|---|---|
| ∠ABD = 28° | 호 AD | 2 × 28° = 56° |
| ∠CAD = 34° | 호 CD | 2 × 34° = 68° |
| ∠BDC = 60° | 호 BC | 2 × 60° = 120° |

> 💡 "어느 호를 바라보는가"는 **각의 꼭짓점을 뺀 두 끝점 사이의 호, 꼭짓점 반대쪽**입니다.

**2단계 — 남은 호 구하기.**
네 호 AD, DC, CB, BA가 원 전체를 이루므로:

호 AB = 360° − 56° − 68° − 120° = **116°**

**3단계 — 구하는 각으로 되돌리기.**
∠ACB는 호 AB를 바라보는 원주각:

**→ 계산: ∠ACB = ½ × 116°**

### 검산
∠ADC = ∠ADB + ∠BDC 가 호 ABC(= 호 AB + 호 BC)의 절반과 같은지 확인해 보면 그림 전체의 일관성을 점검할 수 있습니다.

## 문제 223 — 반원 + 원 밖 교점

### 문제 상황
- AB는 반원 O의 지름. C, D는 반원 위의 점.
- AC와 BD의 연장선이 반원 밖 위쪽 점 P에서 만남. ∠APB = ∠x.
- ∠COD = 32°.
- ∠x는? (보기: 70°~74°)

### 사용 도구
중심각 = 호 (∠COD = 32° → 호 CD = 32°), 도구 7(b) 또는 삼각형 내각합

### 풀이 1 — 외부 교각 공식 (빠른 길)

**1단계**: ∠COD는 중심각이므로 호 CD = 32°.
**2단계**: P의 두 할선(P–C–A, P–D–B)이 원에서 자르는 두 호는
- 먼 호: **호 AB = 180°** (지름이 만드는 호!)
- 가까운 호: **호 CD = 32°**

**3단계**:

**→ 계산: ∠x = ½ × (180° − 32°)**

### 풀이 2 — 삼각형 내각합 (공식의 까닭을 보는 길)

호 AC + 호 DB = 180° − 32° = 148°.
- ∠PAB = ∠CAB는 호 CB = 호 CD + 호 DB 의 원주각 = ½(32° + 호 DB)
- ∠PBA = ∠DBA는 호 AD = 호 AC + 호 CD 의 원주각 = ½(호 AC + 32°)

△PAB에서: ∠x = 180° − ∠PAB − ∠PBA = 180° − ½(64° + 호 AC + 호 DB) = 180° − ½(64° + 148°)

계산해 보면 풀이 1과 정확히 같은 값이 나옵니다. **공식이 왜 성립하는지**를 이 계산이 보여줍니다.

> 💡 보너스 공식: 이 구성에서는 항상 **∠P = 90° − ½∠COD** 입니다. (½(180−h) = 90 − h/2)

## 문제 224 — 지름 위에서 호 쪼개기

### 문제 상황
- AD는 원 O의 지름 (D 위, A 아래). B, C는 오른쪽 반원 위 (A→B→C→D 순서).
- ∠ADB = 33°, ∠CAD = 26°.
- **호 BC에 대한 중심각**은? (보기: 62°~70°)

### 사용 도구
도구 1 (호 = 2 × 원주각), 반원의 호 = 180°

### 풀이

**1단계 — 두 각을 호로 환산.**

**2단계 — 반원에서 호의 합.**
B, C가 모두 지름 AD의 오른쪽 반원 위에 있으므로:

호 AB + 호 BC + 호 CD = 180°

**3단계 — 호 BC 구하기.**

**→ 계산: 호 BC = 180° − 66° − 52°**

**4단계 — 마무리 확인.**
문제가 묻는 것은 "호 BC에 대한 **중심각**"인데, 중심각의 크기는 호의 크기와 같으므로(정의) 3단계의 값이 그대로 답입니다.

## 문제 225 — 반원의 원주각 90° + 피타고라스 두 번

### 문제 상황
- AB는 반원 O의 지름. C(왼쪽 위), D(오른쪽 위)는 반원 위의 점.
- 현 AD와 현 BC가 반원 안의 점 P에서 교차.
- AP = 14, BP = 9, DP = 3.
- 반원 O의 **반지름**은? (주관식)

### 사용 도구
**도구 3 (반원의 원주각 = 90°)**, 피타고라스 정리 × 2

### 풀이

**1단계 — 직각 찾기 (이 문제의 열쇠).**
AB가 지름이고 D가 원 위의 점이므로 **∠ADB = 90°** (도구 3).
→ 현 AD ⊥ 현 DB. 그림에 직각 표시를 해 두세요.

**2단계 — 작은 직각삼각형 PDB에서 DB 구하기.**
∠PDB = 90° (1단계의 직각과 같은 각), PD = 3, PB = 9:

DB = √(PB² − PD²) = √(81 − 9) = √72 = **6√2**

**3단계 — AD의 길이.**
A, P, D는 현 AD 위에 나란히 있으므로:

AD = AP + PD = 14 + 3 = **17**

**4단계 — 큰 직각삼각형 ADB에서 AB(지름) 구하기.**
∠ADB = 90°이므로 피타고라스:

AB = √(AD² + DB²) = √(17² + (6√2)²) = √(289 + 72)

**5단계 — 반지름.**

**→ 계산: 반지름 = √(289+72) ÷ 2** (289 + 72가 어떤 수의 제곱인지 확인해 보세요 — 깔끔하게 떨어집니다!)

### 검산 (방멱: 원 안의 교점 성질)
원 안의 점 P에 대해 PA × PD = PB × PC 가 성립해야 합니다.
14 × 3 = 42 = 9 × PC → PC = 42/9 = 14/3. 모순이 없으므로 구성이 올바릅니다. ✓

## 문제 226 — 지름이 만드는 직각삼각형에서 삼각비

### 문제 상황
- AB는 원 O의 지름 (A 왼쪽, B 오른쪽), C는 원 위(위쪽).
- BC = 12, **BO = 10** (반지름!).
- sin A × cos A × tan A 는? (주관식)

### 사용 도구
도구 3 (반원의 원주각 90°), 피타고라스, 삼각비의 정의

### 풀이

**1단계 — 지름 길이.**
BO는 반지름이므로 AB = 2 × 10 = **20**. (10을 지름으로 쓰지 않도록 주의!)

**2단계 — 직각 찾기.**
AB가 지름 → **∠ACB = 90°** → △ACB는 직각삼각형 (빗변 AB).

**3단계 — 나머지 변.**

AC = √(AB² − BC²) = √(400 − 144) = √256 = **16**

**4단계 — 각 A의 삼각비 읽기.** (각 A 기준: 대변 = BC, 이웃변 = AC, 빗변 = AB)
- sin A = 대변/빗변 = 12/20 = **3/5**
- cos A = 이웃변/빗변 = 16/20 = **4/5**
- tan A = 대변/이웃변 = 12/16 = **3/4**

**5단계 — 곱하기.**

**→ 계산: (3/5) × (4/5) × (3/4)**

### 빠른 검산 (대수적 성질)
sin A × cos A × tan A = sin A × cos A × (sin A / cos A) = **sin²A**.
즉 답은 (3/5)² 과 같아야 합니다. 5단계 결과와 비교해 보세요. ✓

## 문제 227 — tan A로 외접원의 넓이 구하기

### 문제 상황
- △ABC가 원 O에 내접. tan A = 3√3, BC = 9√3.
- 원 O의 **넓이**는? (보기: 60π ~ 64π)

### 사용 도구
tan → sin 변환, **지름 긋기 기법** (도구 2 + 도구 3의 합작 = 사인법칙 2R = a/sin A), 원의 넓이

### 풀이

**1단계 — tan에서 sin 만들기.**
tan A = 3√3 = (높이)/(밑변) 이므로 밑변 1, 높이 3√3인 직각삼각형을 상상합니다.

빗변 = √(1² + (3√3)²) = √(1 + 27) = √28 = 2√7
∴ sin A = 3√3 / (2√7)

**2단계 — 지름 긋기 기법 (이 유형의 핵심 아이디어).**
B를 지나는 **지름 BA′** 를 그립니다. 그러면:
- ∠BA′C = ∠BAC (두 각 모두 호 BC를 바라보는 원주각 — 도구 2)
- ∠BCA′ = 90° (BA′가 지름 — 도구 3)

직각삼각형 A′BC에서: sin(∠BA′C) = BC / BA′, 즉

**2R = BA′ = BC / sin A** ← 각 A가 어디 있든 성립! (사인법칙의 정체)

**3단계 — 반지름 계산.**

2R = 9√3 ÷ [3√3/(2√7)] = 9√3 × (2√7)/(3√3) = 6√7 → R = 3√7

**4단계 — 넓이.**

**→ 계산: 원 O의 넓이 = π × (3√7)²**

### 자주 하는 실수
tan A = 3√3을 sin A로 바꾸지 않고 바로 공식에 넣는 것. 2R = BC/**sin A** 입니다. tan을 쓰려면 반드시 빗변을 만들어 sin으로 변환해야 합니다.

## 문제 228 — 수선의 발이 만드는 "같은 각"

### 문제 상황
- AB(= 6)를 지름으로 하는 반원 O. C는 반원 위의 점.
- C에서 AB에 내린 수선의 발이 D. BC = 2√6.
- ∠ACD = x 일 때, sin x × cos x 는? (주관식)

### 사용 도구
도구 3 (∠ACB = 90°), 피타고라스, **닮음이 만드는 같은 각** (∠ACD = ∠ABC), 삼각비

### 풀이

**1단계 — 직각과 나머지 변.**
AB가 지름 → ∠ACB = 90°.

AC = √(AB² − BC²) = √(36 − 24) = √12 = **2√3**

**2단계 — 각 옮기기 (이 문제의 결정적 아이디어!).**
∠A를 공통으로 쓰는 두 직각삼각형을 봅니다:
- △AC**D** (∠ADC = 90°): ∠ACD = 90° − ∠A
- △AC**B** (∠ACB = 90°): ∠ABC = 90° − ∠A

둘 다 "90° − ∠A"이므로:

**∠ACD = ∠ABC = x**

> 💡 까닭: 직각삼각형에 빗변으로 수선을 내리면 원래 삼각형과 닮은 삼각형이 생기고(AA 닮음), 닮은 삼각형끼리는 대응각이 같습니다. "작은 삼각형 속 각 x를 큰 삼각형에서 읽을 수 있게 되는" 마법의 열쇠입니다.

**3단계 — 큰 삼각형에서 x의 삼각비 읽기.**
△ACB에서 x = ∠ABC 기준 (대변 AC, 이웃변 BC, 빗변 AB):
- sin x = AC/AB = 2√3/6 = **√3/3**
- cos x = BC/AB = 2√6/6 = **√6/3**

**4단계 — 곱하고 정리.**

**→ 계산: sin x × cos x = (√3/3) × (√6/3)** — 분자 √18을 3√2로 정리하세요.

### 검산 (작은 삼각형에서 직접)
CD = AC·BC/AB = (2√3 × 2√6)/6 = 2√2, AD = AC²/AB = 12/6 = 2.
△ACD에서 직접: sin x = AD/AC = 2/(2√3) = √3/3 ✓, cos x = CD/AC = 2√2/(2√3) = √6/3 ✓ — 완벽히 일치.

## 문제 233 — 호 3등분 + 원 밖 교점

### 문제 상황
- 원 위의 네 점 A, B, C, D에서 **호 AB = 호 BC = 호 DA**.
- AD와 BC의 연장선이 원 밖 P에서 만남. ∠P = 44°.
- ∠ADB를 구하시오. (주관식)

### 사용 도구
미지수 설정(호), 호의 합 = 360°, 도구 7(b) (원 밖 교각), 도구 1

### 풀이

**1단계 — 미지수 설정.**
호 AB = 호 BC = 호 DA = x 라 하면, 남은 호 CD = 360° − 3x.

**2단계 — 원 밖 교각 공식 적용.**
P에서 볼 때 가까운 호는 AB, 먼 호는 CD이므로 (도구 7(b)):

∠P = ½ × (호 CD − 호 AB)
44° = ½ × [(360° − 3x) − x] = ½(360° − 4x) = 180° − 2x

**3단계 — 방정식 풀기.**

2x = 180° − 44° = 136° → x = **68°** (= 호 AB)

**4단계 — 원주각으로.**
∠ADB는 호 AB를 바라보는 원주각이므로:

**→ 계산: ∠ADB = ½ × 68°**

### 검산
호 CD = 360° − 3×68° = 156° > 0 ✓ (호가 음수면 설정이 틀린 것!)
½×156° − ½×68° = 78° − 34° = 44° = ∠P ✓

## 문제 234 — 반원에서 호의 이등분점

### 문제 상황
- AB는 반원 O의 지름. C, D는 반원 위의 점 (A → C → D → B 순서).
- **호 BD = 호 CD** (D는 호 CB의 중점), ∠ABC = 42°.
- ∠CBD는? (보기: 16° / 20° / (가려짐) / 28° / 32°)

도구 1, 반원의 호 = 180°, 호의 이등분

### 풀이

**1단계 — 주어진 각을 호로.**
∠ABC = 42° → 호 AC = 2 × 42° = **84°**.

**2단계 — 남은 호.**
호 CB = 180° − 84° = **96°**.

**3단계 — 이등분.**
호 CD = 호 DB이므로 D는 호 CB의 중점:

호 CD = 호 DB = 96° ÷ 2 = **48°**

**4단계 — 원주각으로.**
∠CBD는 호 CD를 바라보는 원주각:

**→ 계산: ∠CBD = ½ × 48°**

### 참고 (보기 ③이 안 보이는 까닭)
사진에서 보기 ③이 접힌 페이지에 가려져 있는데, 보기가 16°, 20°, ?, 28°, 32°로 **4° 간격 등차수열**이므로 ③의 값을 재구성할 수 있고, 계산 결과와 일치합니다.

### 검산
∠ABD = ∠ABC + ∠CBD = 42° + (구한 값). 이것이 호 AD = 84° + 48° = 132°의 절반과 같은지 확인. ✓

## 문제 235 — 우각(반대쪽 큰 중심각) 240° 읽기

### 문제 상황
- 원 O 위의 점 P, A, B. 그림에서 **P를 포함하지 않는 쪽** 호 AB의 중심각(우각) ∠AOB = 240°.
- 호 PB = ⅓ × 호 PA.
- ∠PBA는? (보기: 42° / 45° / 48° / 51° / 54°)

### 사용 도구
중심각의 합 = 360°, 비례배분, 도구 1

### 풀이

**1단계 — 남은 중심각 계산.**
P를 포함하는 쪽(호 PA + 호 PB)의 중심각 합:

360° − 240° = **120°**

> ⚠️ 그림의 240°는 **P 반대쪽**에 표시된 우각입니다. 이걸 놓치고 240°를 P쪽으로 쓰면 전부 어긋납니다.

**2단계 — 3 : 1로 나누기.**
호 PB = ⅓ 호 PA → 호 PA : 호 PB = 3 : 1. 중심각도 같은 비율이므로:

호 PA의 중심각 = 120° × 3/4 = **90°**, 호 PB의 중심각 = 120° × 1/4 = 30°

**3단계 — 원주각으로.**
∠PBA는 꼭짓점이 B이므로 **호 PA**(B를 포함하지 않는 호)를 바라봅니다:

**→ 계산: ∠PBA = ½ × 90°**

### 검산 (삼각형 내각합)
∠PAB = ½ × 30° = 15°, ∠APB = ½ × 240° = 120°.
15° + (구한 값) + 120° = 180° 이 되는지 확인하세요. ✓

## 문제 236 — 중심에서 같은 거리에 있는 두 현

### 문제 상황
- △ABC의 외접원 중심 O에서 현 AB, AC에 내린 수선의 발이 각각 M, N. **OM = ON**.
- ∠ACB = 75°, 호 AB의 길이 = 25π.
- 호 BC의 **길이**를 구하시오. (주관식)

### 사용 도구
**중심과 현의 거리 성질**, 이등변삼각형, 도구 6 (호 길이 ∝ 원주각)

### 풀이

**1단계 — OM = ON 해석 (이 문제의 시작점).**
한 원에서 **중심으로부터 같은 거리에 있는 두 현은 길이가 같습니다.**

*까닭*: 중심에서 현에 내린 수선은 현을 이등분합니다. 반현의 길이 = √(반지름² − 거리²) 이므로 거리가 같으면 현 길이도 같습니다. ∎

∴ **AB = AC** → △ABC는 이등변삼각형.

**2단계 — 각 채우기.**
∠ABC = ∠ACB = 75° (이등변 밑각) → ∠BAC = 180° − 75° − 75° = **30°**.

**3단계 — 호의 길이 비례 (도구 6).**
호의 길이는 그 호를 바라보는 원주각에 정비례:
- 호 AB ← 원주각 ∠ACB = 75°
- 호 BC ← 원주각 ∠BAC = 30°

호 AB : 호 BC = 75 : 30 = 5 : 2

**4단계 — 계산.**

**→ 계산: 호 BC = 25π × (30/75)**

### 검산
원주 전체 = 25π × (360/150)… 대신 간단히: 호 AC도 25π(AB=AC이므로), 세 호의 합 = 25π + 25π + (구한 값) 이 원주가 되고, 원주각 합 75+75+30 = 180° ✓.

## 문제 237 — 한 원에 내접한 정삼각형과 정사각형

### 문제 상황
- 원 O에 정삼각형 ABC와 정사각형 ADEF가 **함께 내접** (꼭짓점 A 공통).
- 호 DB의 길이 = 5π.
- 원 O의 **반지름**을 구하시오. (주관식)

### 사용 도구
정n각형이 원을 n등분하는 성질, 호의 길이 공식: 호 = 2πr × (중심각/360°)

### 풀이

**1단계 — 정다각형이 만드는 호.**
내접 정다각형의 꼭짓점들은 원을 똑같이 나눕니다:
- 정사각형 ADEF: 이웃 꼭짓점 사이 호 = 360° ÷ 4 = **90°** → 호 AD = 90°
- 정삼각형 ABC: 이웃 꼭짓점 사이 호 = 360° ÷ 3 = **120°** → 호 AB = 120°

**2단계 — 호 DB 계산.**
그림에서 D와 B는 A로부터 **같은 방향**에 있으므로 (A → D → B 순):

호 DB = 호 AB − 호 AD = 120° − 90° = **30°**

**3단계 — 호의 길이 공식으로 방정식 세우기.**
반지름을 r라 하면:

5π = 2πr × (30/360) = 2πr × 1/12 = πr/6

**4단계 — r 풀기.**

**→ 계산: r = 5π × 6 ÷ π**

### 검산
구한 r로 원주 2πr를 계산하면, 호 DB(= 원주의 1/12)가 정말 5π가 되는지 확인. ✓

## 문제 238 — 호의 비 3 : 4 : 5로 세 내각 나누기

### 문제 상황
- 호 AB : 호 BC : 호 CA = 3 : 4 : 5.
- ∠BAC = a°, ∠ABC = b°, ∠BCA = c°.
- b − a + c 는? (보기: 60 / 65 / 70 / 75 / 80)

### 사용 도구
도구 6, **"한 원의 모든 호에 대한 원주각의 합 = 180°"**

### 풀이

**1단계 — 왜 합이 180°인가.**
세 호 AB + BC + CA = 360°(원 전체)이고 원주각은 호의 절반이므로,
세 원주각의 합 = ½ × 360° = **180°**. (삼각형 내각합 180°와 정확히 일치 — 우연이 아닙니다!)

**2단계 — 각이 어느 호를 보는지 짝짓기 (실수 최다 구간!).**
삼각형의 각 꼭짓점은 **자기 맞은편 호**를 바라봅니다:

| 각 | 바라보는 호 | 비의 몫 | 크기 |
|---|---|---|---|
| c° = ∠BCA | 호 **AB** | 3/12 | 180° × 3/12 = 45° |
| a° = ∠BAC | 호 **BC** | 4/12 | 180° × 4/12 = 60° |
| b° = ∠ABC | 호 **CA** | 5/12 | 180° × 5/12 = 75° |

> ⚠️ a°가 3/12 몫이 아닙니다! ∠A는 호 BC(4의 몫)를 바라봅니다. 짝을 잘못 지으면 보기에 있는 그럴듯한 오답이 나오도록 설계된 문제입니다.

**3단계 — 요구식 계산.**

**→ 계산: b − a + c = 75 − 60 + 45**

### 검산
a + b + c = 60 + 75 + 45 = 180 ✓

## 문제 239 — 대관람차 10칸 (그림 판독 주의보!)

### 문제 상황
- 대관람차의 10개 칸이 원 위에 **일정한 간격**으로 배치.
- 그림에서 두 선분이 그어져 있고 그 사이 각이 ∠x.
- ∠x를 구하시오. (주관식)

### 사용 도구
등분 → 한 칸 사이 호 = 360° ÷ 10 = 36°, **도구 7(a) (원 안 교각 = 마주 보는 두 호의 합의 절반)**

### ⚠️ 검증 과정에서 잡아낸 함정
1차 풀이에서는 "한 칸에서 그은 두 현(원주각)"으로 읽었으나, 사진을 확대 재판독한 결과 두 선분은 **서로 다른 두 현**이고 원 **안에서 교차**합니다:
- 현 1: 10시 방향 칸 → 1시 방향 칸
- 현 2: 11시 방향 칸 → 5시 방향 칸 (원의 중심 근처를 지남)
- ∠x는 두 현의 **교점에서 왼쪽으로 벌어진 각**.

그림을 잘못 읽으면 풀이 전체가 무너지는 전형적인 문제입니다. 문제를 풀기 전에 "각의 꼭짓점이 원 위인가, 안인가, 밖인가"부터 확인하세요 — 적용 공식이 완전히 달라집니다.

### 풀이

**1단계 — 한 칸 사이 호.**
10등분이므로 이웃 칸 사이 호의 중심각 = 360° ÷ 10 = **36°**.

**2단계 — ∠x가 마주 보는 두 호 세기.**
교점 기준으로 ∠x(와 그 맞꼭지각)가 잘라내는 두 호는:
- 위쪽: 두 시작 칸(10시, 11시) 사이 → 칸 간격 **1개분 = 36°**
- 아래쪽(반대편): 두 끝 칸(1시, 5시) 사이 → 칸 간격 **3개분 = 108°**

**3단계 — 원 안 교각 공식 (도구 7(a)).**

**→ 계산: ∠x = ½ × (36° + 108°)**

### 까닭 다시 확인 (외각 정리로)
교점을 P, 두 현을 CD(10시→1시), AB(11시→5시)라 하면 △APC에서 ∠x는 외각:
∠x = ∠PAC + ∠PCA = (호 CB의 원주각) + (호 DA의 원주각) = ½(4칸) + ½(2칸) — 계산하면 3단계와 같은 값이 나옵니다. ✓

## 문제 240 — 같은 호 2쌍 + 원 안 교점 (합만 알면 되는 문제)

### 문제 상황
- 원 위에 A, B, C, D, E. **호 AB = 호 BC**, **호 AE = 호 ED**.
- P = 현 AD ∩ 현 BE, Q = 현 AC ∩ 현 BE.
- ∠DAC = 34°.
- ∠APQ는? (보기: 71°~75°)

### 사용 도구
도구 1 (각 → 호), 호의 합 = 360°, 도구 7(a) (원 안 교각)

### 풀이

**1단계 — 주어진 각을 호로.**
∠DAC = 34°는 호 DC를 바라보는 원주각 → **호 DC = 68°**.

**2단계 — 미지수 설정과 "합" 구하기 (이 문제의 묘미).**
호 AB = 호 BC = a, 호 AE = 호 ED = b 라 하면, 원 전체:

2a + 2b + 68° = 360° → **a + b = 146°**

> 💡 a와 b를 **각각** 구할 수는 없습니다(조건 부족). 그런데 곧 보겠지만 답은 a + b만 필요합니다. "따로는 몰라도 합은 안다" — 잘 설계된 문제의 전형적인 장치입니다.

**3단계 — 원 안 교각 공식.**
현 AD와 현 BE의 교점 P에서 (도구 7(a)):

∠APB = ½ × (호 AB + 호 ED) = ½ × (a + b)

**4단계 — ∠APQ = ∠APB인 까닭.**
Q는 현 BE 위의 점이고, 그림에서 Q는 P보다 B쪽에 있습니다.
따라서 반직선 PQ와 반직선 PB는 **같은 반직선** → ∠APQ = ∠APB.

**5단계 — 계산.**

**→ 계산: ∠APQ = ½ × 146°**
